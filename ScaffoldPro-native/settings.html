Share with Other Macs

Work on the same data from several Macs

Several people work on the same projects and documents, each on their own Mac, through a folder shared in iCloud Drive. A change made on one Mac appears on the others by itself, usually within seconds.

To set it up:

  1. On this Mac, press Share My Data… and choose a folder in iCloud Drive (for example your shared Proficiency folder). ScaffoldPro makes a ScaffoldPro Team folder there and copies in your data and project files.
  2. In Finder, share that folder with the others if it isn't shared already: Control-click it › Share › Share Folder…, add them, and set Permission to Can make changes.
  3. On each of their Macs: install ScaffoldPro, accept the invitation, then in Settings press Join a Shared Folder… and choose the ScaffoldPro Team folder.

Joining leaves that Mac's own data untouched — it comes back if sharing is turned off there.

Backup & Restore

Backups, restoring, automatic iCloud backup

A backup is a complete copy of everything — the database, every project folder with its drawings and PDFs, and the company documents — in one folder you can also copy to a USB drive.

Automatic backups: ScaffoldPro also makes a backup by itself every day at 12:00 a.m. and 12:00 p.m. (or as soon as it's open again, if the Mac was asleep or ScaffoldPro was closed then). Automatic backups more than 3 days old are deleted; backups you make yourself are kept.

Local Copy in Documents

While ScaffoldPro works from the shared folder, the project files live there — so Documents › ScaffoldPro on this Mac is kept up to date as a local copy of everything (Database, Projects, Administration). Only what changed is copied, about a minute after anything is saved, every 15 minutes and when ScaffoldPro opens; nothing is deleted from it. Files that are still only in iCloud are downloaded and copied on a later run. It can be restored with Restore from Folder….

Google Sheets

An overview sheet kept in step both ways

A Google Sheet with Projects, Activity and Overview tabs, kept in step with ScaffoldPro both ways about every minute while ScaffoldPro is open on this Mac. Change a project's Stage or Notes in the sheet and ScaffoldPro is updated; lines typed into Activity are added to its history.

Google Sheet—
The sheet still runs a script pasted before it could update itself. Paste ScaffoldPro's script into its Apps Script once more, run setup, then Deploy › Manage deployments › ✏️ › New version › Deploy. From then on new layouts arrive by themselves.
  1. 1
    Make a Google Sheet (sheets.new) and name it, e.g. “ScaffoldPro Overview”. Share it with whoever should see it.
  2. 2
    In the sheet: Extensions › Apps Script. Delete what's there and paste ScaffoldPro's script, then save. (If that menu won't open, make the project at script.google.com instead: the sheet's link is already filled in at the top of the script, in SHEET_URL.)
  3. 3
    In the list next to Run / Debug, choose setup (not onOpen), then press Run and allow it to use the sheet. If Google says the app isn't verified, choose Advanced › Go to … (it's your own script). It makes the tabs and shows a connection secret (also in the Execution log).
  4. 4
    Deploy › New deployment › type Web app. Execute as: Me; Who has access: Anyone. Deploy and copy the Web app URL.
  5. 5
    Paste both here and press Connect.

Set it up on one Mac — the office Mac that's usually open — and that Mac keeps the sheet up to date for everyone. The URL and secret are kept on this Mac only.

AI Import

Reading old quotations and scans

Importing a quotation (Project › Quotations › Import…) reads the file on this Mac first. When it can’t make out the items — a scan, a photo, an unusual layout — a free cloud AI can read it instead. You always check what it read before a quotation is made.

  1. 1
    Choose a provider.
  2. 2
    Get a free key.
  3. 3
    Paste it here and save.

The key is kept in this Mac’s Keychain, and nothing is sent until you import a file. Only that file (or its text) goes to the provider. On free tiers the provider may use what’s sent to improve its models, so don’t use it for anything confidential.
