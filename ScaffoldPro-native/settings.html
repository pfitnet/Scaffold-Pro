Share with Other MacsWork on the same data from several Macs through iCloud Drive
Several people can work on the same projects, quotations and documents, each on their own Mac, with no server: the data lives in a folder you all share in iCloud Drive (free with every Apple ID). When someone saves a change, it appears on the other Macs by itself — usually within a few seconds, as soon as iCloud has carried it across.

To set it up:

  1. On this Mac, press Share My Data… and choose a folder in iCloud Drive (for example your shared Proficiency folder). ScaffoldPro makes a ScaffoldPro Team folder there and copies in your data and project files.
  2. In Finder, share that folder with the others if it isn't shared already: Control-click it › Share › Share Folder…, add them, and set Permission to Can make changes.
  3. On each of their Macs: install ScaffoldPro, accept the invitation, then in Settings press Join a Shared Folder… and choose the ScaffoldPro Team folder.

Joining leaves that Mac's own data untouched — it comes back if sharing is turned off there.

Backup & RestoreBackups, restoring, automatic iCloud backup
A backup is a complete copy of everything — the database, every project folder with its drawings and PDFs, and all worker and company documents — saved as one folder you can also copy to a USB drive. Backups are kept with the database (Library ▸ Application Support ▸ ScaffoldPro ▸ Backups), away from the business files in Documents.

Automatic backups: ScaffoldPro also makes a backup by itself every day at 12:00 a.m. and 12:00 p.m. (or as soon as it's open again, if the Mac was asleep or ScaffoldPro was closed then). Automatic backups more than a week old are deleted; backups you make yourself are kept.

Local Copy in Documents

While ScaffoldPro works from the shared folder, the project files live there — so Documents › ScaffoldPro on this Mac is kept up to date as a local copy of everything (Database, Projects, Administration). Only what changed is copied, about a minute after anything is saved, every 15 minutes and when ScaffoldPro opens; nothing is deleted from it. Files that are still only in iCloud are downloaded and copied on a later run. It can be restored with Restore from Folder….

Automatic iCloud Backup

Keeps an up-to-date copy of everything — the database, every project folder and all worker and company documents — straight into the shared iCloud Drive folder Proficiency › William's Work (its Database, Projects, Administration, Configuration and Database History folders). It updates itself about a minute after anything is saved, every 15 minutes, and when ScaffoldPro opens; only files that changed are copied. A copy of the database is also kept for each of the last 30 days. Nothing is ever deleted from the iCloud copy. To restore from it, use Restore from Folder… above and choose the William's Work folder.

UpdatesNew versions of ScaffoldPro from GitHub

ScaffoldPro checks for a new version when it opens (and, with this ticked, every 30 minutes while it’s open). When there is one it asks; Update Now saves what you’re working on, makes a backup, updates and opens again by itself.

Needed when the Scaffold-Pro repository on GitHub is private — without it, ScaffoldPro can’t see or download new versions by itself. On github.com: Settings › Developer settings › Personal access tokens › Fine-grained tokens › Generate new token; choose only the Scaffold-Pro repository, and under Repository permissions set Contents: Read-only. It’s kept on this Mac only (in a file only your Mac account can read).

Web AccessScaffoldPro in a web browser, for the team’s Windows PCs, iPads and phones

This Mac serves ScaffoldPro to web browsers on the office network. Everyone signs in with their name and the office password below, and works on the same data — it’s saved through this Mac into the shared folder, like any other Mac’s work. It’s always this Mac’s version, so it updates when this Mac does. Keep ScaffoldPro open on this Mac (it won’t let the Mac fall asleep while Web Access is on).

From outside the office: install the free Tailscale app on this Mac and on each person’s PC or phone (signed in to the same Tailscale account), then use this Mac’s Tailscale address with the same port. Files are made here and downloaded; choosing files to upload, imports, backups and setup still need a Mac.
